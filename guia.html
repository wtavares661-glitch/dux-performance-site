Este é o passo a passo completo: instalar o VS Code, conectar o Claude Code, gerar o token do Meta Ads e liberar o acesso à API do Google Ads. Feito uma vez, serve para sempre.

Como usar este guia

Leia isto primeiro. São 2 minutos e evita 90% dos problemas.

O guia é linear: faça as partes na ordem. Se você já tem alguma etapa pronta (já tem MCC, já usa VS Code), pode pular, mas confira o checklist do final antes de dizer que terminou.

💡 Comece pelo Meta, que dá menos trabalho

A parte do Meta você resolve em uns 10 minutos e já sai daqui com o token na mão. O Google é mais burocrático e ainda passa por uma aprovação humana que costuma levar de 24 horas a 7 dias. Por isso a ordem do guia é essa: primeiro o Meta, para você já ver a coisa funcionando, e depois o Google. Se você usa muito Google Ads e tem pressa, dá para adiantar o pedido de acesso na Parte 5 e voltar para o começo enquanto a resposta não chega.

⚠️ Estamos falando de tecnologia: parte disto vai envelhecer

Meta, Google, Claude e VS Code mexem nas telas e nos nomes dos menus o tempo todo. É bem possível que, quando você estiver lendo, um botão esteja em outro canto ou com outro nome, ou que apareça uma etapa nova que não existia aqui. Isso não significa que você errou.

  • Procure pela palavra-chave do passo (ex.: "Central de API", "Credenciais", "Explorador da Graph API") em vez de procurar pelo botão exatamente como está descrito.
  • O caminho lógico muda muito pouco: criar aplicativo, dar permissões, gerar token, guardar a chave.
  • Quando empacar, use o atalho que a maioria dos tutoriais não tem: pergunte para a própria IA, descrevendo a tela que você está vendo. Tem uma seção só sobre isso no final, com prompts prontos para copiar.

Parte 0

O que você precisa ter antes de clicar em qualquer coisa

Nada aqui é opcional. Se faltar um item desta lista, o passo a passo trava no meio.

Contas e assinaturas
  • Assinatura do Claude: o plano de entrada já resolve. É ela que libera o Claude Code que vamos instalar.
  • Perfil pessoal do Facebook com acesso de administrador aos ativos abaixo.
  • Gerenciador de Negócios (BM): é dentro dele que o aplicativo do Meta vai nascer.
  • Pelo menos uma conta de anúncios do Meta e uma página do Facebook vinculadas a essa BM.
  • Conta do Google Ads ativa (uma sua ou de cliente que você administra).
  • Um site ou landing page da sua operação. O Google exige uma URL no formulário de liberação da API. Sem site, o pedido não anda.
  • Um bloco de notas fechado (ou gerenciador de senhas) para colar os tokens conforme forem aparecendo.
🔒 Sobre os tokens que você vai gerar

Um token de acesso é, na prática, o seu login, a sua senha e o seu segundo fator resumidos numa linha de caracteres. Quem tiver o token entra nas suas contas de anúncio sem precisar de mais nada.

  • Nunca mande token em grupo de WhatsApp, e-mail, chat de suporte ou print de tela.
  • Nunca cole token dentro da conversa com uma IA. O lugar dele é só no arquivo de configuração.
  • Se desconfiar que vazou, veja como revogar na caixa de emergência da Parte 3.

Parte 1

Instalar o VS Code

O VS Code nasceu como programa de programador, mas é um ótimo lugar para rodar o Claude Code: você abre várias conversas ao mesmo tempo, enxerga as pastas dos seus clientes em tempo real e compartilha essa mesma estrutura com o time. É gratuito.

💡 O editor não precisa ser o VS Code

Existem outros editores que fazem o mesmo papel, como Cursor, Antigravity e outros que vão surgindo. Vários deles são, inclusive, feitos em cima do próprio VS Code, então a lógica de pastas, extensões e atalhos é praticamente a mesma. Use o que você preferir.

Aqui as telas foram feitas no VS Code, por ser gratuito e o mais comum. Se você escolher outro, os nomes dos menus podem mudar um pouco, mas o caminho é o mesmo: instalar o editor, instalar a extensão, fazer login e abrir uma pasta de trabalho.

Download e instalação

Baixe em code.visualstudio.com

O site detecta o seu sistema sozinho, mas confira antes de clicar. Escolha a sua aba abaixo.

  1. Clique no botão azul de download. Vai baixar um arquivo .exe (User Installer, o recomendado).
  2. Abra o arquivo baixado. Aceite o contrato e vá clicando em Avançar.
  3. Na tela de tarefas adicionais, marque "Adicionar ao PATH" e "Adicionar a ação Abrir com Code". Isso facilita a vida depois.
  4. Clique em Instalar e depois em Concluir. O VS Code abre sozinho.
💡 Atalhos do Windows que vão aparecer neste guia
  • Salvar arquivo: Ctrl + S
  • Copiar o caminho de um arquivo: segure Shift, clique com o botão direito no arquivo e escolha "Copiar como caminho".
  1. Clique no botão de download. Confira se é a versão do seu chip (Apple Silicon M1/M2/M3 ou Intel). Na dúvida, escolha Universal.
  2. Vai baixar um arquivo .zip. Clique duas vezes para descompactar.
  3. Arraste o ícone do Visual Studio Code para dentro da pasta Aplicativos. Esse arrastar é a instalação.
  4. Abra pelo Launchpad. Na primeira vez o Mac pergunta se você confia no programa, confirme.
💡 Atalhos do Mac que vão aparecer neste guia
  • Salvar arquivo: Cmd + S
  • Copiar o caminho de um arquivo: clique com o botão direito, segure a tecla Option (⌥) e a opção muda para "Copiar [arquivo] como nome do caminho".
Opcional, mas recomendado para iniciantes

Deixar o VS Code em português

  1. Com o VS Code aberto, clique no ícone de Extensões na barra lateral esquerda (parece quatro quadradinhos).
  2. Pesquise por Portuguese (Brazil) e instale a versão oficial da Microsoft.
  3. Vai aparecer um aviso no canto inferior direito: clique em "Change Language and Restart".
  4. O programa reinicia já em português.
💡 Não estranhe o inglês que sobra

Mesmo em português, várias mensagens do Claude continuam em inglês (o famoso Yes / No nas confirmações). É normal e não indica erro.

Parte 2

Instalar e conectar o Claude Code

Aqui você liga a sua assinatura do Claude ao VS Code e cria a pasta que vai virar, na prática, o segundo cérebro da sua operação.

💡 Você não é obrigado a usar o Claude Code

Existem outras inteligências artificiais que trabalham no mesmo formato, dentro do editor e com acesso às suas pastas, como o Codex e outras que aparecem a cada mês. Você é livre para escolher a que preferir, e nada impede que você tenha mais de uma instalada na mesma pasta de trabalho.

O que você precisa saber é que toda a configuração apresentada aqui foi feita com o Claude Code: os prints, os nomes de tela e os prompts seguem esse caminho. A lógica vale para as outras (instalar, dar acesso à pasta, guardar as chaves num arquivo local), mas os passos exatos mudam de ferramenta para ferramenta.

Etapa 2.1

Instalar a extensão oficial

  1. No VS Code, abra Extensões na barra lateral.
  2. Pesquise por Claude Code.
  3. Instale a primeira da lista, publicada pela Anthropic (a empresa dona do Claude). Existem imitações com nome parecido, confira o nome do publicador antes de clicar.
  4. Se o VS Code perguntar se você confia no publicador, confirme.
  5. Terminou a instalação, aparece um novo ícone do Claude na barra lateral. Clique nele.
⚠️ Windows: pode pedir mais uma coisa

Em alguns computadores Windows a extensão pede para instalar componentes extras (por exemplo o Git) na primeira execução. Pode autorizar: é parte normal da instalação e vem das fontes oficiais. Se aparecer uma mensagem que você não entendeu, copie o texto e cole no chat do Claude perguntando o que é.

Etapa 2.2

Fazer login com a sua assinatura

  1. No painel do Claude que abriu dentro do VS Code, escolha a opção de entrar com a assinatura Claude (Claude.ai subscription), e não com chave de API.
  2. Ele abre o navegador. Se você já está logado no Claude por ali, é só Autorizar.
  3. Volte para o VS Code. A partir daqui a sua assinatura vale também dentro do editor.

Traduzindo o que acabou de acontecer: você disse ao Claude "quero te usar também neste outro programa".

Etapa 2.3 · a mais importante

Criar a pasta de trabalho

O Claude Code trabalha sempre dentro de uma pasta. Tudo o que estiver nela, ele enxerga: contexto dos clientes, criativos, planilhas, relatórios. Tudo o que estiver fora, ele não enxerga. Por isso essa etapa define se a sua experiência vai ser organizada ou caótica.

  1. Vá em Arquivo › Abrir Pasta.
  2. Escolha um lugar fácil de achar: a pasta Documentos resolve. Evite salvar na Área de Trabalho bagunçada.
  3. Crie uma pasta nova com um nome curto e sem acento. Exemplo: operacao ou agencia.
  4. Selecione a pasta e clique em Abrir.
  5. O VS Code pergunta se você confia nos autores dessa pasta. Como foi você quem acabou de criar, confirme.
⚠️ O ícone do Claude sumiu quando abri a pasta

Acontece o tempo todo: ao trocar de pasta, o VS Code remonta a tela inteira. Duas saídas: clique de novo no ícone do Claude na barra lateral, ou aperte Ctrl/Cmd + Shift + P, digite Claude Code e escolha o comando de abrir o painel.

Etapa 2.4

Antes de instalar qualquer material de terceiros, mande verificar

Se você vai instalar um framework, um pacote de skills ou qualquer coisa baixada da internet, peça uma inspeção antes. Leva um minuto e é a diferença entre instalar uma ferramenta e instalar um problema.

Prompt de verificação
Quero instalar este material no meu computador. Antes de instalar, faça uma auditoria:
me diga o que ele contém, se existe algo malicioso, se algum script envia dados para
fora, para quais domínios ele se conecta e se em algum momento ele pede ou expõe as
minhas senhas ou tokens. Me responda em português e de forma simples.

[cole aqui o link ou o caminho do material]

Uma resposta saudável menciona: os arquivos são de texto/documentação, o tráfego de rede vai só para as APIs oficiais (graph.facebook.com, googleads.googleapis.com) e as credenciais são lidas de um arquivo local que você cria. Se a resposta apontar qualquer envio para domínio desconhecido, não instale.

💡 Camada extra de segurança

Para arquivos baixados, você também pode passar o link ou o arquivo no VirusTotal antes. É gratuito.

Etapa 2.5 · opcional

Reduzir a quantidade de confirmações

Por padrão o Claude pede autorização a cada ação. É seguro, e é chato. Existe um modo que reduz isso (as chamadas bypass permissions), configurável nas Configurações do VS Code pesquisando por permissions.

🔒 Leia antes de ligar

Com esse modo ligado, o que você pedir ele executa, inclusive apagar arquivo ou publicar campanha. O próprio programa exibe um aviso de risco na hora de ativar. Recomendação para quem está começando: deixe desligado nos primeiros dias, até pegar o jeito de escrever pedidos precisos. Ligue depois, se quiser.

Parte 3

Gerar o token do Meta Ads

Este é o bloco mais curto do guia: em 10 minutos você tem o aplicativo criado e o token na mão. Você vai sair daqui com duas informações guardadas: o ID do aplicativo e o token de acesso.

Etapa 3.1

Criar o aplicativo

  1. Acesse developers.facebook.com logado no perfil do Facebook que administra a sua BM.
  2. Vá em Meus aplicativos e clique em Criar aplicativo.
  3. Dê um nome (ex.: Claude Code Agencia) e informe o seu e-mail. Clique em Avançar.
  4. Na pergunta sobre o caso de uso, escolha Outro, é o caminho mais curto. Avance.
  5. No tipo do aplicativo, escolha Empresa.
    Não escolha "Consumidor": com esse tipo o acesso às contas de anúncio não funciona.
  6. Selecione a BM que o aplicativo vai usar e clique em Criar aplicativo.
  7. Pode ser que ele peça a sua senha ou um código de verificação por e-mail. Normal.
💡 Guarde agora o ID do aplicativo

Assim que o aplicativo é criado, o ID aparece no painel dele (e também na lista em "Meus aplicativos"). É um número comprido. Copie e cole no seu bloco de notas, você vai precisar dele na Parte 6.

Etapa 3.2

Escolher as permissões e gerar o token

  1. No menu superior, vá em Ferramentas › Explorador da Graph API.
  2. No canto direito, em Aplicativo do Meta, selecione o aplicativo que você acabou de criar. Se o seu perfil já tinha outros aplicativos, é fácil errar aqui, confira o nome.
  3. Abra a lista de Permissões e marque as que estão na tabela abaixo.
  4. Clique em Gerar token de acesso.
  5. Ele pergunta quais páginas liberar. Escolher "todas as páginas atuais e futuras" evita ter que refazer isso a cada cliente novo.
  6. Depois pergunta quais empresas (BMs) liberar. Mesma lógica.
  7. Confirme. O token aparece no campo de cima. Ainda não é o token final: falta a etapa 3.3.

💡 Dá para voltar depois

Esqueceu uma permissão ou quer liberar uma BM nova? É só voltar ao Explorador da Graph API, ajustar as marcações e gerar o token de novo. O token antigo continua valendo até expirar.

Etapa 3.3 · não pule

Transformar o token de 1 hora em token longo

O token que você acabou de gerar dura cerca de uma hora. Com uma hora não dá para trabalhar. A conversão para o token longo leva 20 segundos.

  1. Copie o token gerado.
  2. Vá em Ferramentas › Depurador de token de acesso.
  3. Cole o token no campo e clique em Depurar.
  4. Role até o fim da página e clique em Estender token de acesso.
  5. Um novo token aparece embaixo. Esse é o token que você vai usar. Copie e guarde no bloco de notas.
⚠️ Confira a data de expiração na própria tela

O token estendido é chamado de "longa duração" e costuma valer cerca de 60 dias. A tela do depurador mostra a data exata de expiração. É essa data que vale, não o que qualquer tutorial disser. Anote-a e crie um lembrete no celular para uma semana antes. No dia, você repete só a Parte 3 e troca a linha do token no arquivo de configuração.

💡 E o token que nunca expira?

Existe. Não vamos ensinar aqui de propósito: um token permanente vazado é um problema permanente. Enquanto você não recupera o acesso ao perfil para revogá-lo, ele continua valendo. O ciclo de renovação periódica é mais chato e muito mais seguro.

Fechando a Parte 3

Existem outros caminhos, e todos são válidos

O caminho acima é o mais direto para quem está começando do zero. Mas ele não é o único.

  • Aplicativo que você já tem. Se no seu developers.facebook.com já existe um aplicativo do tipo Empresa, criado por você ou pelo seu time, você pode simplesmente usar esse aplicativo em vez de criar outro. Basta selecioná-lo no Explorador da Graph API e seguir da etapa 3.2 em diante. Não há vantagem em ter aplicativos duplicados.
  • Modelo de usuário do sistema (System User). É o outro formato de token do Meta, gerado dentro das configurações do seu Gerenciador de Negócios, em Usuários › Usuários do sistema. A diferença principal é que esse token é permanente: não tem data de expiração e você não precisa renovar a cada dois meses. É o formato preferido de quem já tem intimidade com a ferramenta e de operações maiores.
⚠️ Se optar pelo token permanente, redobre o cuidado

A comodidade de não renovar vem com o outro lado: um token que não expira sozinho continua valendo para sempre se cair em mãos erradas, até que alguém o revogue manualmente. Guarde num gerenciador de senhas, nunca compartilhe e, se houver qualquer suspeita, revogue o usuário do sistema imediatamente nas configurações do Gerenciador de Negócios.

Emergência

Desconfiou que o token vazou? Faça isto agora

  1. Entre nas configurações de segurança do seu perfil do Facebook e troque a senha.
  2. Na tela de troca de senha, procure a opção de sair de todos os dispositivos / encerrar todas as sessões e marque.
  3. Isso invalida o token na hora. Depois é só gerar um novo seguindo a Parte 3 de novo.

Marcar essa caixinha é o passo que a maioria esquece, e é justamente ele que derruba o token.

⚠️ Vá com calma nos primeiros dias. Leia isto antes de sair usando.

A conexão é oficial: tudo aqui passa pelas APIs do Facebook e do Google, os mesmos canais que as ferramentas do mercado usam há anos. Isso não é gambiarra e não é o que derruba conta.

Mas existe um detalhe que ninguém conta: aplicativo recém-criado, usado com muito empenho logo de cara, chama atenção. Mesmo que o seu perfil e as suas contas sejam antigos, um aplicativo novo que dispara centenas de ações em poucas horas pode acabar bloqueado. Vale o mesmo princípio de sempre: assim como dentro do gerenciador de anúncios, o que você faz e o volume com que faz podem levar a bloqueio, independente da ferramenta.

  • Nos primeiros dias, use em ritmo normal de trabalho. Consultas, relatórios, uma campanha por vez.
  • Evite rodar bateladas gigantes logo depois de criar o aplicativo (subir dezenas de campanhas ou centenas de criativos de uma vez, por exemplo).
  • Se algo der erro repetido, pare e entenda o motivo em vez de mandar rodar de novo em sequência.
  • O que bloqueia conta continua sendo o que sempre bloqueou: anúncio fora da política. Automatizar a operação não é infração. Publicar o que não pode, é.
Parte 4

Criar o MCC do Google Ads

O MCC é a conta de administrador do Google Ads. Pense nele como o equivalente à BM, só que do lado do Google. Sem MCC você não consegue o developer token, e sem developer token nada do Google Ads funciona. Se você já tem um, pule para a Parte 5.

Etapa 4.1

Criar a conta de administrador

  1. Acesse ads.google.com/home/tools/manager-accounts e clique em Criar uma conta de administrador.
  2. Dê um nome fácil de reconhecer, no formato MCC + nome da sua operação.
  3. Preencha país Brasil, o seu fuso horário e a moeda Real brasileiro (BRL).
  4. Na pergunta sobre o uso, escolha gerenciar minhas contas (e não "gerenciar contas de outras pessoas").
  5. Confirme o captcha e finalize. A conta nasce vazia.
⚠️ Fuso e moeda não mudam depois

Esses dois campos ficam travados após a criação. Confira antes de clicar em criar.

Etapa 4.2

Vincular as suas contas de anúncio ao MCC

Criar o MCC não conecta nada sozinho. Você precisa puxar cada conta para dentro dele. É o mesmo movimento de adicionar uma conta de anúncio numa BM.

  1. Dentro do MCC, vá em Contas (vai estar vazia) e escolha Vincular conta existente.
    O mesmo caminho existe em Configurações de subconta.
  2. Você precisa do ID da conta de anúncio que quer vincular. Ele aparece no topo da tela quando você abre aquela conta no Google Ads, no formato 123-456-7890.
  3. Cole o ID e envie a solicitação.
  4. Chega um convite no e-mail do administrador daquela conta (se for sua, no seu e-mail mesmo). Abra e clique em aceitar solicitação › permitir acesso.
  5. O Google pode pedir para você confirmar a identidade. Confirme.
  6. Volte ao MCC: a conta agora aparece na lista.
💡 Não achou o e-mail?

O convite também aparece como notificação dentro da conta de anúncio (ícone de sininho) e em Administrador › Acesso e segurança › Administradores. Se nada aparecer, confira se você enviou o convite para o ID certo: um dígito trocado envia para outra conta.

Parte 5 · a mais longa

Liberar os acessos da API do Google Ads

O Google é mais burocrático que o Meta: são vários cliques e uma aprovação humana no final. Respire. São quatro informações a coletar, e este guia vai dizer exatamente onde cada uma aparece.

⚠️ Confira em qual conta Google você está logado

Este é o erro clássico desta parte. Se você tem mais de uma conta Google no navegador, o formulário pode abrir na conta errada e o pedido é recusado sem explicação. Antes de começar: saia das outras contas ou use uma janela anônima logada apenas na conta dona do MCC.

Etapa 5.1

Criar um projeto no Google Cloud

  1. Acesse console.cloud.google.com.
  2. No seletor de projetos (no topo), clique em Novo projeto.
  3. Dê um nome: Claude Code serve. Organização pode ficar em branco.
  4. Clique em Criar, espere alguns segundos e depois em Selecionar projeto. Confirme no topo da tela que o projeto selecionado é esse.
Etapa 5.2

Ativar a Google Ads API

  1. No menu lateral, vá em APIs e serviços › Biblioteca.
  2. Pesquise por Google Ads API.
  3. Abra o resultado e clique em Ativar.
Etapa 5.3

Configurar a tela de permissão OAuth

É o "aplicativo" do Google, equivalente ao que você criou no Meta.

  1. Vá em APIs e serviços › Tela de permissão OAuth e clique em Começar.
  2. Nome do app: algo reconhecível, ex.: Claude Code. E-mail de suporte: o seu.
  3. Em tipo de público, escolha Externo.
  4. Preencha os dados de contato, aceite os termos e clique em Criar.
  5. Agora vá em Acesso a dados › Adicionar ou remover escopos. No filtro, digite Ads.
  6. Marque o escopo da Google Ads API (.../auth/adwords), clique em Atualizar e depois em Salvar.
  7. Vá em Público-alvo › Usuários de teste, adicione o seu próprio e-mail e salve.
💡 Por que adicionar a si mesmo como "usuário de teste"?

Porque o aplicativo fica em modo de teste, e só quem está nessa lista consegue autorizá-lo. Se pular este passo, na hora do login final vai aparecer "Acesso bloqueado".

Etapa 5.4 · guarde estas duas

Criar as credenciais (Client ID e Client Secret)

  1. Vá em APIs e serviços › Credenciais.
  2. Clique em Criar credenciais › ID do cliente OAuth.
  3. Em tipo de aplicativo, escolha App para computador.
  4. Clique em Criar. Aparecem o ID do cliente e a Chave secreta do cliente.
  5. Copie os dois para o bloco de notas. São informações sigilosas, do mesmo nível do token do Meta.
Etapa 5.5 · guarde esta

Pegar o Developer Token no MCC

  1. Volte ao Google Ads, dentro do MCC (é obrigatório ser o MCC; conta comum não tem essa opção).
  2. Vá em Administrador (ou Ferramentas e configurações) › Central de API.
  3. Preencha o formulário: e-mail de contato, nome da empresa, tipo de negócio (agência / anunciante) e a descrição de uso. Tem um texto sugerido logo abaixo.
  4. Deixe claro que você não fornece esses dados a terceiros e que as contas gerenciadas são da sua própria operação e dos seus clientes.
  5. Aceite os termos e clique para criar o token.
  6. Clique em Ver token, copie e guarde no bloco de notas.
Descrição de uso · versão em português
Somos uma agência de marketing digital que gerencia campanhas de Google Ads para
os nossos próprios clientes, com contas vinculadas à nossa conta de administrador (MCC).

Vamos usar a API exclusivamente para uso interno da agência: criar e gerenciar
campanhas de rede de pesquisa e Performance Max, gerenciar palavras-chave e extrair
relatórios de desempenho para acompanhamento dos nossos clientes.

Não desenvolvemos nem revendemos software. Não fornecemos, vendemos nem compartilhamos
os dados obtidos pela API com terceiros. Todo o acesso é restrito à nossa equipe interna
e às contas que já administramos.

We are a digital marketing agency managing Google Ads campaigns for our own clients.

⚠️ Adapte o texto à sua realidade

Use como base, mas escreva a verdade sobre a sua operação. O Google avisa no próprio formulário: informação incorreta é motivo de recusa.

Etapa 5.6 · a que demora

Solicitar o Acesso Básico

O token que você acabou de gerar é um token de teste: serve para testar, mas não acessa as suas contas reais. Para valer, você precisa pedir o Basic Access.

  1. Ainda na Central de API, clique em Solicitar acesso básico (Apply for Basic Access).
  2. Confirme que o e-mail de contato é o mesmo cadastrado no MCC.
  3. Informe o ID do MCC, que aparece no topo da tela do Google Ads, no formato 123-456-7890. Se você digitar errado, o formulário acusa na hora.
  4. Pergunta se você tem representante do Google: se não tiver, marque que não.
  5. Informe o site da sua empresa. Campo obrigatório: é aqui que quem não tem site trava.
  6. Na descrição de uso, cole o texto da etapa anterior.
  7. Tipos de campanha: marque os que você realmente usa (ex.: Search e Performance Max).
  8. Recursos que pretende usar: marque criação de campanha, gerenciamento de campanha, relatórios e palavras-chave.
    Sugestão: não marque criação nem gerenciamento de contas. É raro ser aprovado e você continua criando conta na mão sem prejuízo nenhum.
  9. Aceite os termos e envie.
⏳ Agora é esperar

A resposta chega por e-mail, normalmente entre 24 horas e 7 dias. Enquanto isso, siga com a Parte 6 usando a parte do Meta, ela funciona de forma independente.

Etapa 5.7

Anotar o Login Customer ID

É simplesmente o ID do seu MCC, sem os hífens.

  • Na tela: 616-544-8598
  • Como você vai usar: 6165448598

Tirar os hífens não é frescura: com eles, a conexão falha.

📋 Fechando a Parte 5, você deve ter 4 informações guardadas
  • Client ID: do Google Cloud (etapa 5.4)
  • Client Secret: do Google Cloud (etapa 5.4)
  • Developer Token: da Central de API do MCC (etapa 5.5)
  • Login Customer ID: o ID do MCC sem hífens (etapa 5.7)
Parte 6

Conectar tudo: o arquivo .env

Todas as chaves que você juntou moram num único arquivo de texto, que fica só no seu computador e nunca é enviado para lugar nenhum. Quem cria esse arquivo é o próprio Claude, você só preenche as linhas.

Etapa 6.1

Rodar a configuração

  1. Com a sua pasta de trabalho aberta no VS Code, abra o painel do Claude.
  2. Peça a configuração da conexão com o Meta. Ele vai: conferir se o Python está instalado (e instalar, se não estiver), instalar o SDK oficial e criar o arquivo .env em branco.
  3. Autorize as instalações que ele pedir. São pacotes oficiais.
  4. Quando o arquivo .env abrir na tela, preencha as linhas do Meta.

⚠️ Os três erros que travam 9 em cada 10 pessoas aqui
  • Colar fora das aspas. Se a linha tem aspas, o valor vai dentro delas.
  • Esquecer de salvar. Aperte Ctrl + S (Windows) ou Cmd + S (Mac). A bolinha branca ao lado do nome do arquivo tem que sumir.
  • Deixar hífen no Login Customer ID. Tem que ser só dígitos.
Etapa 6.3 · só Google

A autorização final do Google

Depois do .env salvo, o Claude abre o navegador para você autorizar o acesso.

  1. Escolha a conta Google certa, a mesma do MCC.
  2. Vai aparecer um aviso de que o app está em teste. É esperado (foi você quem criou). Clique em Continuar.
  3. Conceda a permissão. Pronto: o refresh token é salvo sozinho.
  4. Volte ao VS Code e deixe ele rodar o teste de conexão.
⚠️ Apareceu "Acesso bloqueado"?

Quase sempre é uma de duas coisas: você autorizou com a conta Google errada, ou esqueceu de se adicionar como usuário de teste na etapa 5.3. Corrija e peça ao Claude para rodar a autorização de novo.

Etapa 6.4

Cadastrar as suas contas de uma vez

Com a conexão funcionando, ele consegue listar todas as contas de anúncio às quais você tem acesso e salvar num arquivo de referência (normalmente contas.yaml). A partir daí você para de colar ID: passa a falar por nome.

Prompt · cadastrar as contas
Liste todas as contas de anúncio às quais eu tenho acesso e salve no arquivo
contas.yaml, com nome do cliente, nome da conta e ID. Se não conseguir
identificar o cliente pelo nome da conta, me pergunte antes de preencher.
💡 Diferença entre Meta e Google aqui

No Meta, o nome da conta costuma já identificar o cliente e o preenchimento sai quase automático. No Google Ads essa informação nem sempre vem, então você vai precisar dizer quem é quem. Pode fazer isso depois, aos poucos: peça para ele salvar só os IDs agora.

Prompt · primeiro teste de verdade
Me traga um resumo da conta [nome do cliente] dos últimos 7 dias: investimento,
impressões, alcance, frequência, cliques, CTR, CPC, CPM e resultados. Depois liste
as campanhas ativas e as pausadas no período.

Se voltou com os números batendo com o gerenciador, está tudo funcionando. Fim da instalação.

Parte 7

Quatro hábitos que fazem diferença desde o primeiro dia

Não é instalação, é rotina. Mas evita retrabalho e economiza consumo.

01
Uma tarefa, uma aba nova Terminou uma tarefa, abra outra conversa. Cada mensagem faz o Claude reler tudo o que já está na tela. Conversa longa e cheia de arquivos consome muito mais e responde pior.
02
Renomeie os históricos Dê nome a cada conversa ("Relatório cliente X", "Campanha de alcance"). Depois você acha tudo pelo botão de histórico. Detalhe importante: o histórico só aparece se você estiver na mesma pasta onde a conversa aconteceu.
03
Trabalhe sempre dentro da pasta Perdeu o histórico ou "o Claude esqueceu tudo"? Quase sempre é porque o VS Code está com outra pasta aberta. Vá em Arquivo › Abrir Pasta e volte para a sua.
04
Alimente o contexto Uma pasta por cliente, com um arquivo descrevendo negócio, oferta e objetivo. Quanto mais contexto, menos você repete instrução, e melhor fica o resultado.
💡 Caminho de arquivo: o jeito rápido

Quando precisar mandar criativos, em vez de descrever onde estão, copie o caminho e cole na conversa: no Mac, botão direito + segurar Option (⌥) › "Copiar como nome do caminho"; no Windows, Shift + botão direito › "Copiar como caminho".

Problemas mais comuns

Antes de pedir socorro, confira aqui

O ícone do Claude sumiu do VS Code

Aperte Ctrl/Cmd + Shift + P, digite Claude Code e escolha o comando de abrir o painel. Se mesmo assim não aparecer, confira se a extensão continua instalada e se você está com uma pasta aberta (Arquivo › Abrir Pasta).

Criei uma skill nova e ela não aparece na lista

A lista de comandos é carregada quando a janela abre. Feche e reabra o VS Code, ou use Ctrl/Cmd + Shift + P para recarregar a janela. Depois ela aparece normalmente.

"Acesso bloqueado" na autorização do Google

Duas causas quase sempre: conta Google errada no navegador, ou o seu e-mail não foi adicionado como usuário de teste na tela de permissão OAuth (etapa 5.3). Corrija e rode a autorização de novo.

O Meta parou de responder e fala em sessão inválida

Provavelmente o token expirou (lembre-se: o token estendido vale por tempo limitado) ou a senha do perfil foi trocada com a opção de encerrar sessões. Refaça a Parte 3, gere um token novo e troque só aquela linha do .env.

Meu developer token do Google não acessa as contas reais

Ele ainda está como token de teste. Você precisa do Acesso Básico aprovado (etapa 5.6). A resposta chega por e-mail em 24 horas a 7 dias. Sem essa aprovação, nada do Google Ads funciona de verdade.

Criei tudo, mas nenhuma conta aparece

No Meta: confira se você marcou ads_management e business_management nas permissões e se liberou a BM certa ao gerar o token. No Google: confira se as contas estão vinculadas ao MCC (Parte 4) e se o Login Customer ID está sem hífens.

Ele criou a campanha, mas errou um detalhe

Isso é esperado e é justamente por isso que tudo é criado pausado. Confira geolocalização, orçamento, posicionamentos e criativos no gerenciador antes de ativar. Achou um erro, é só apontar: ele corrige. Trate o resultado como rascunho de um assistente, não como entrega final.
